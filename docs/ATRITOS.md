# Atritos do uso real

Problemas anotados durante o treino (tarefa 6.1 do `PLANO.md`). Anote na hora, do jeito que der; a análise fica para depois. No fim das duas semanas, os 5 piores viram correção.

**Gravidade**
- **alta**: meta errada, dado perdido, treino ou aviso no dia errado, app travou.
- **média**: deu para registrar, mas com volta ou retrabalho (toques a mais, tive que desfazer).
- **baixa**: incômodo de texto, layout ou espera.
